// 3 slender trunks and 20 spruce twigs is blocked.
//
// Use file rename adding or removing boff_ before the biy_XXX
// to control if this is active.



.Shelter. [effort:2] [phys:arms,stance,one-armed] -S- *BUILDING* /30/	[assist:2]	%30%
{Cutting weapon} <Axe> [wearpct:30]
{Slender trunk} (3) [remove] [ground]
{Spruce twig} (20) [remove] [ground]


-end
