////////////////////////
// Bloomery
//
// A bloomery is a vertical intense heat chamber where raw ore
// is heated to the point that the liquid can flow. 
// Gravity and bouyancy principles seperate materials.
// While the iron, being at welding heat, binds together.
// It is an impure process and will need follow up work.
//
// Weblinks on bloomery
// https://www.youtube.com/watch?v=gDy1jx6mLgs&t=436s
// https://www.youtube.com/watch?v=FUhv2OnVVDU
// https://www.youtube.com/watch?v=F3rjjpuhCLI&t=22s
// https://www.youtube.com/watch?v=bajwZPebm-g&list=PL-vRsHsClLJ4yu4Vcs9nIhm5pGhxnJ5W6
// 
// The option for useing the game's fireplace as a forge 
// exists. It has many qualities in terms of structure
// similiar to a bloomery. It is possible to build
// an extra fireplace as a smithy.
//
// In terms of later recipes the calls are for *forge
// so both work equally well.

/////////////
// Turning iron into steel
//
// Steel is iron with a small amount, e.g. 1% or less, of carbon
// distributed through the iron. Steel making is not something 
// where you lose a large amount iron. Rather you put that small
// amount of carbon all across the material to 'carburize' it.
// The carbon could be charcoal or other sources though charcoal
// is already available to the smith. The portion is so small as
// to be not directly reprsented in the recipe.
// There are key challenges:
// 1) The amount of carbon in the iron for useful steel
// 2) That it is all mixed together
// Mixing takes alot of folding, twisting and repeating until
// the mix is even. All the while the metal needs to be hot.
// Actual historic work might build an item, like an axe head
// then treat just the edges that need to be steel.
// Our game recipes don't currently work that way.
//
// Weblinks: (modern and historic)
// https://www.youtube.com/watch?v=gDy1jx6mLgs
// https://www.youtube.com/watch?v=omGKUKwJPB8
// https://www.youtube.com/watch?v=xs75yCmfTS4
