//
//
//>>>>>>>>>>>>>>>>>>>>>
// How to code the different hammer technology
//
// {Rock} for very basic hit with anything, no leverage
// {*hammer} for Stone hammer or better
// {*iron hammer} when you need Flat iron hammer or better
// {Ball iron hammer} for the best type of hammer only
//
/////////////////////
// How to code for Adze axe technology
//
// {*adze axe} to allow the easy to make Stone adze axe
// {Iron adze axe} to require the advanced metal adze
//
