// Caulking
// Caulking is set as for #1# per length of tree ~3-4 meters as 
// #0.5# pitch glue and #0.5# branches 50/50
// While ideally hemp there are very many possibilities to get
// at least a basic caulking. The branch represents some form of 
// of plant matter.

.Caulking. "Hunting horn" [patch:3] [noquality] [phys:arms] [effort:0] *CARPENTRY*    /15/ \30\  |-2|
{*glue} (1) [remove] [ground] [patchwise]
{*fibre from *} #1# [remove] [ground] [patchwise] [noquality]
{*pot} (1) [ground] '+to hold hot caulking'
{Fire}      '+to soften pitch'
{Firewood} (1) [remove] [ground] [patchwise] '+to sustain fire'
[WEIGHT:2]
[PRICE:0]
[TILEGFX:bc-pitchglue]
// Patch limited to size of pot #6# contents
// Time based largely on whittling/feathering/breaking plant 
// material as it is is stirred into warm pitch glue
// In later centuries caulking used fibers from worn out ropes
// for better quality. Here bits of wood represented by branches
// perform that role.
