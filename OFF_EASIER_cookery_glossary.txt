////////////////////////
// On cooking times
//
// There are 2 time commands available with the /#Active/ being 
// time the character is involved and all recipes seem to have 
// that. The other time is marked with the other slashes as 
// \#Unavailable\. This is the unavailable time that an object 
// exists but can't be interacted with. On checking the files 
// and how they were written I can see in at least some cases 
// there is the logic that after the time interacting,
// /#Active/, that it would be ready for consumption without any 
// /#Unavailable/ time alloted.
//
